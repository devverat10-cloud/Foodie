Sensory Appetite-Trigger Welcome

Instead of abstract vector illustrations, high-definition floating food photography (grilled chicken salad bowl) is front and center. This directly stimulates the user's hunger response, increasing the psychological readiness to complete onboarding.

  • ✦ Single primary CTA avoids decision paralysis (Hick's Law).
  • ✦ Welcoming microcopy: "Good Food Happy Mood" reinforces positive mood association.
  • ✦ High-contrast orange pill button (#FF7600) achieves 4.9:1 WCAG AA compliance.

Information Architecture

End-to-End User Journey Wireflow

Structured logic mapping every state transition, entry point, fallback loop, and decision gate in the Figma prototype.

STATE 01
Initial Splash Hook
First impression with chef hat branding and vivid healthy food imagery. Clicking "Get Started" progresses directly to discovery.
STATE 02
Value Onboarding (2 Cards)
Card 1 focuses on craving variety ("For Every Mood"). Card 2 focuses on speed & local curation. Quick "SKIP" keeps power users unhindered.
STATE 03
Authentication Gate
Dual login with phone/email support, inline password visibility toggle, and instant Google 1-Tap sign-in.
STATE 04
Account Recovery & 2FA
Single-field password reset triggers a 5-digit verification SMS with an active countdown timer (02:04) and instant resend.
UI Breakdown

High-Fidelity Screen Architecture

Click on any screen card to inspect high-resolution details, typography hierarchy, and UI component choices.

Screen 01 • Entry

Welcome Splash Screen

Minimalist header with iconic chef hat icon, warm greeting tagline, and an appetizing bowl of grilled chicken salad. Anchored by a full-width high-contrast primary CTA.

Screen 02 • Discovery

Sensory Cravings Hook

Dynamic 3D gourmet burger with molten cheddar splash bursting outside the orange circular framing. Prominent skip link and circular floating arrow button.

Screen 03 • Discovery

Curated Restaurants

Highlights local culinary selection with flying twirled pasta and fresh basil. Interactive pagination indicator reflects current carousel state.

Screen 04 • Auth

Welcome Back (Sign In)

Friction-free input fields with leading icons for email/phone and password. Integrated "Forgot Password?" affordance and Google Social SSO button.

Screen 05 • Registration

Personalized Sign-Up

Profile avatar badge encourages immediate account personalization. Minimal 3 fields (Full Name, Contact, Password) ensure high conversion.

Screen 06 • Recovery

Password Recovery

Dedicated recovery pathway with empathetic subtitle ("Don't worry, we'll help you reset it") and single focus field to prevent drop-off.

Screen 07 • Security

5-Digit SMS Verification

Discrete, spacious 5-digit OTP input boxes with rounded corners. Dynamic countdown timer ("Resend code in 02:04") prevents rapid spamming.
